# Sample Syllabus: Computer Networks & Distributed Systems (Semester VII)

## Unit 1: Physical and Data Link Layer Fundamentals
- Overview of Network Architecture, OSI and TCP/IP Reference Models
- Framing, Error Detection and Correction (CRC, Hamming Codes, Checksum)
- Flow Control Mechanisms: Stop-and-Wait, Sliding Window (Go-Back-N, Selective Repeat)
- Medium Access Control: Pure ALOHA, Slotted ALOHA, CSMA/CD, CSMA/CA
- Ethernet Standards and High-Speed LANs

## Unit 2: Network Layer and Routing Algorithms
- Network Layer Design Issues, Store-and-Forward Packet Switching
- IPv4 Addressing, Subnetting, Classless Inter-Domain Routing (CIDR), NAT
- IPv6 Addressing and Transition Strategies
- Routing Algorithms: Shortest Path Routing (Dijkstra), Distance Vector (Bellman-Ford), Link State Routing
- Hierarchical Routing, Broadcast and Multicast Routing
- Congestion Control: Leaky Bucket, Token Bucket Algorithms

## Unit 3: Transport Layer Protocols and End-to-End Delivery
- Transport Service Primitives, Berkeley Sockets API Overview
- User Datagram Protocol (UDP): Packet Structure, Use Cases, Limitations
- Transmission Control Protocol (TCP): Connection Establishment (3-Way Handshake), Termination
- TCP Flow Control, Congestion Control (Tahoe, Reno, Vegas, CUBIC)
- Quality of Service (QoS): Integrated and Differentiated Services

## Unit 4: Application Layer Protocols and Web Architecture
- Domain Name System (DNS): Hierarchical Namespace, Resource Records, Resolution Strategies
- Hypertext Transfer Protocol (HTTP/1.1, HTTP/2, HTTP/3): Request-Response, Headers, Persistent Connections
- Email Architecture: SMTP, POP3, IMAP
- File Transfer Protocol (FTP) and Secure Copy (SCP)
- Socket Programming in Python: TCP Echo Client-Server, Multi-threaded Chat Server

## Unit 5: Network Security and Modern Topics
- Cryptography Essentials: Symmetric (AES) vs. Asymmetric (RSA, ECC), Hash Functions (SHA-256)
- Message Authentication Codes (MAC) and Digital Signatures
- Secure Sockets Layer / Transport Layer Security (SSL/TLS) Handshake
- Firewalls, Intrusion Detection Systems (IDS), and Network Address Translation
- Software-Defined Networking (SDN) and Cloud Networking Basics
